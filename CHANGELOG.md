# Changelog

## [0.1.0] - 2026-07-29

### Added

- Local-first Rust orchestration runtime distributed through
  `@jonathlima/orquestra`.
- Autonomous `orquestra-init` discovery, research, confidence convergence,
  adaptive planning, skill routing, execution, rerouting, and verification flow.
- Portable setup for Codex, Claude Code, OpenCode, and Antigravity.
- Seven bundled Orquestra Agent Skills, including focused grilling with optional
  consented document review.
- Host MCP/WIE web-research delegation with cross-source validation and
  project-local memory.
- Deterministic DAG waves, checkpoints, BRAIN quarantine, model routing, and
  evidence-based ticket verification.
- Native package targets for Windows x64, macOS x64/ARM64, and Linux x64/ARM64.

### Security

- Literal-argv verification pipelines, write-root enforcement, output limits,
  secret redaction, private-network source rejection, and external BRAIN disabled
  by default.
